# Security Policy

## Supported Scope

Security reports are accepted for active content in this repository, including:
- workflow files in .github/workflows
- orchestration and governance scripts
- dependency manifests and lock files

## Reporting a Vulnerability

Please report vulnerabilities privately using GitHub Security Advisories:
- Security tab -> Report a vulnerability

If private advisory reporting is unavailable, open a private maintainer contact request and do not disclose exploit details publicly.

## Response Process

Maintainers will:
1. acknowledge receipt
2. assess severity and impact
3. prepare remediation
4. coordinate disclosure timing

## Disclosure Guidance

Please avoid public disclosure until a fix or mitigation has been published.
