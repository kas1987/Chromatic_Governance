# Decision Rules

Use these rules when agents disagree or authority is unclear.

1. Explicit user instructions beat inferred preferences.
2. Current source files beat stale summaries.
3. Passing tests beat unverified claims, but tests do not override security concerns.
4. Security and data integrity concerns can block convenience or speed.
5. Reversible decisions can proceed with lower ceremony than irreversible ones.
6. When evidence is insufficient, choose the safest reversible next step or escalate.
7. A decision must identify the owner and validation path.
