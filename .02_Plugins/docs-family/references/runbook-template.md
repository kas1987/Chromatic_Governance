# Runbook Template

```markdown
# Runbook: System or Procedure

## When to use this

Trigger conditions and scope.

## Owner and escalation

Primary owner, backup, escalation path.

## Prerequisites

Access, tools, environment, dashboards, secrets references.

## Prechecks

Safe checks before state-changing work.

## Procedure

Numbered steps with commands and expected output.

## Verification

How to confirm the procedure worked.

## Rollback or recovery

How to return to safe state.

## Known risks

Data loss, downtime, security, cost, or customer impact.

## Related docs

Monitoring, troubleshooting, release, security, architecture.
```
