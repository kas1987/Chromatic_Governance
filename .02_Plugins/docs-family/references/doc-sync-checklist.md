# Doc Sync Checklist

Use after code, config, API, release, or workflow changes.

## Identify affected docs

- README or quick start
- API reference
- Developer guide
- Runbook
- Troubleshooting guide
- Architecture docs or diagrams
- Release notes or changelog

## Sync rules

1. Match docs to the actual change, not the original plan.
2. Update examples when behavior or commands changed.
3. Update warnings when risk changed.
4. Update links when files moved.
5. Add TODO markers only for real unknowns.
6. Record owner-review items separately.
