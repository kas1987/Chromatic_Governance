# README Template

Use this structure when creating or refreshing a README.

```markdown
# Project Name

One paragraph: what this is, who it is for, and what problem it solves.

## Status

Stable, experimental, internal, deprecated, or WIP. Include support limits.

## Quick start

1. Install prerequisites.
2. Configure environment.
3. Run the smallest useful command.
4. Verify success.

## Usage

Common workflows with examples.

## Project structure

Key directories and files.

## Development

Setup, test, lint, validate, and contribution flow.

## Operations

Runbook, deployment, monitoring, and troubleshooting links.

## Security and secrets

Safe config guidance. Never include real secrets.

## Documentation map

Links to API docs, runbooks, architecture, changelog, and support docs.
```
