# Doc Audit Template

| Severity | Finding | Evidence | Impact | Recommended action | Owner |
|---|---|---|---|---|---|

| High | Stale API field | Docs vs schema | Integration breakage | Update API docs | TBD |
| Medium | Missing link | README | Navigation friction | Add link | TBD |
| Low | Style mismatch | Guide | Minor confusion | Clean up later | TBD |

## Severity rules

- Blocker: prevents install, operation, release, or safe usage
- High: likely causes wrong implementation, outage, security issue, or user-facing confusion
- Medium: creates avoidable friction or incomplete understanding
- Low: polish, wording, or organization issue
