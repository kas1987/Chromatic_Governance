# API Docs Template

For each API, command, function, schema, or plugin interface:

```markdown
## Interface name

Purpose and audience.

### Stability

Stable, experimental, deprecated, internal, or unknown.

### Authentication and permissions

Required access and trust boundaries.

### Request or input

Fields, types, required values, constraints, examples.

### Response or output

Fields, types, meanings, examples.

### Errors

Error code or symptom, likely cause, caller action.

### Side effects

Files written, state changed, external calls, cost, or rate limits.

### Examples

Minimal working example and one realistic example.
```
