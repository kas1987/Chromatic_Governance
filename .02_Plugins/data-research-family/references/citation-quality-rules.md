# Citation Quality Rules

## Claim support statuses

- Supported: source directly supports the claim.
- Partially supported: source supports part but not the full wording.
- Overstated: claim goes beyond source evidence.
- Unsupported: citation does not support the claim.
- Contradicted: source conflicts with the claim.
- Stale: source may once have supported the claim but freshness risk is high.

## Audit rules

- One citation can support multiple claims only if each claim is directly present or inferable with low ambiguity.
- Do not use a source for a broader claim than it makes.
- Prefer primary sources for current technical behavior.
- Vendor sources support vendor positioning, not neutral market truth.
- Community sources support observed user reports, not universal facts.
