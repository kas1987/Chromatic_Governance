# Change Impact Matrix

| Impact area | Questions |
|---|---|
| Code | Which modules, APIs, commands, or data paths change? |
| Config | Are env vars, flags, permissions, or defaults changed? |
| Data | Are schemas, migrations, retention, or contracts affected? |
| Security | Are auth, secrets, permissions, or exposure surfaces affected? |
| QA/eval | Which tests, fixtures, golden cases, or evals need updates? |
| Docs | Which README, API docs, runbooks, or troubleshooting docs change? |
| Release | Is rollout, rollback, versioning, or monitoring affected? |
