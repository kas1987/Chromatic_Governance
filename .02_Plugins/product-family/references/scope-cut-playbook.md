# Scope Cut Playbook

## Cut order

1. Duplicative polish that does not change user success.
2. Multi-persona support before the primary persona works.
3. Edge integrations not required for the core journey.
4. Admin/reporting layers that can be manual for MVP.
5. Automation that can temporarily be human-in-the-loop.
6. Customization before default workflow validation.

## Do not cut

- Security and privacy requirements
- Data-loss prevention
- Migration safety
- Rollback path for production releases
- Basic observability for production-impacting changes
- Accessibility essentials for target users
