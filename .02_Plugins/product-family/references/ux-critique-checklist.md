# UX Critique Checklist

## Review areas

- User goal is obvious within the first screen or step.
- Primary action is visually and linguistically clear.
- Secondary actions do not compete with the primary action.
- Navigation explains where the user is and what happens next.
- Empty, loading, error, and success states are handled.
- Copy uses the user's language rather than internal jargon.
- Trust cues are present before sensitive actions.
- Accessibility basics are respected: contrast, labels, keyboard path, focus order, readable text, meaningful errors.
- Cognitive load is proportional to the task.
- The flow has a clear recovery path after mistakes.

## Finding severity

- Blocker: prevents task completion or causes serious error.
- Major: creates hesitation, confusion, or avoidable abandonment.
- Minor: friction or polish issue.
- Nice-to-have: improves experience but is not urgent.
