# ADR Template

```markdown
# ADR-<number>: <Decision title>

## Status
Proposed / Accepted / Rejected / Deprecated / Superseded

## Context
What forces, constraints, prior decisions, or problems made this decision necessary?

## Decision
What did we decide?

## Options considered
### Option A: <name>
- Pros:
- Cons:

### Option B: <name>
- Pros:
- Cons:

## Consequences
### Positive
- <benefit>

### Negative
- <cost or risk>

### Neutral / operational
- <maintenance, migration, documentation, or ownership impact>

## Follow-up
- <action>

## Revisit when
- <condition that would make this decision stale>
```

ADR rules:

- One durable decision per ADR.
- Use `proposed` until approved.
- Use `superseded` instead of rewriting history.
- Keep it factual and compact.
