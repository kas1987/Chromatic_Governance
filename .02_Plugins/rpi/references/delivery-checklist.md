# RPI Delivery Checklist

## Before work

- [ ] Goal is clear.
- [ ] Scope and non-goals are explicit.
- [ ] Acceptance criteria are defined.
- [ ] Risk tier is understood.
- [ ] Required permissions are available.

## During work

- [ ] Changes are small and reviewable.
- [ ] Existing conventions are preserved.
- [ ] Decisions are recorded.
- [ ] Tests or checks are run when available.
- [ ] Scope creep is rejected or deliberately re-planned.

## Before handoff

- [ ] Changed files are listed.
- [ ] Validation evidence is included.
- [ ] Risks and unknowns are stated.
- [ ] Next action is clear.
