# RPI Review Rubric

| Rating | Meaning | Action |
|---|---|---|
| Pass | Meets scope and validation evidence is sufficient. | Accept or move to release/docs handoff. |
| Pass with notes | Works, but has non-blocking risks or polish items. | Accept with tracked follow-ups. |
| Partial | Some criteria met, but gaps remain. | Continue implementation or testing. |
| Fail | Does not meet core requirements or introduces unacceptable risk. | Stop and remediate. |
| Not verified | Evidence is insufficient. | Run checks or reduce confidence. |

Review should prioritize correctness, safety, maintainability, test evidence, and user value in that order unless the user sets a different priority.
