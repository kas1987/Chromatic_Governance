# Interactive GUI Platforms

## Local/custom

React/Vite, Next.js, SvelteKit, Vue, Gradio, Streamlit, NiceGUI, PySide/PyQt, Tkinter, Textual, Bubble Tea, Electron, Tauri.

## Public/hosted

Figma, Framer, Webflow, Retool, Appsmith, ToolJet, Bubble, app generators, Vercel/Netlify dashboards, Observable, CodeSandbox/StackBlitz.

## Selection criteria

Use case, user count, data sensitivity, auth needs, deployment target, interactivity, design fidelity, cost, exportability, vendor lock-in, and maintainer skill.
