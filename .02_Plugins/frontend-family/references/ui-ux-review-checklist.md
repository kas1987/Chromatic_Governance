# UI/UX Review Checklist

- User task is obvious within five seconds.
- Primary action is visually and semantically clear.
- Layout works on target breakpoints.
- Keyboard navigation is possible.
- Focus states are visible.
- Text contrast is sufficient.
- Loading, empty, error, and success states exist.
- Forms provide validation and recovery guidance.
- Motion is useful, not decorative noise.
- Performance budget is respected.
