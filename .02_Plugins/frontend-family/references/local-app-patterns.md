# Local App Patterns

- TUI: best for power-user workflows, terminals, logs, and local ops.
- CLI: best for repeatable automation.
- Local web app: best for dashboards and forms.
- Desktop app: best for file-heavy or offline workflows.
- Electron: broad web ecosystem, heavier runtime.
- Tauri: lighter desktop shell, more systems setup.
- Python GUI: useful for prototypes and local tools.
