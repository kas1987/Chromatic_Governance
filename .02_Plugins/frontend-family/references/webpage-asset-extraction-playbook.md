# Webpage Asset Extraction Playbook

1. Confirm permission to inventory or reuse the webpage assets.
2. Capture source URL or local HTML path.
3. Inventory HTML, CSS, JS, images, fonts, icons, video/audio, and 3D assets.
4. Separate first-party assets from third-party CDN/library assets.
5. Record license/ownership status where known.
6. Produce a migration manifest with target folder names and reuse recommendations.

## Manifest fields

Asset path or URL, type, source page/file, dimensions or size when known, license/ownership note, keep/replace/recreate decision, target destination.
