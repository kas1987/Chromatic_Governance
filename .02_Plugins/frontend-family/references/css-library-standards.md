# CSS Library Standards

A CSS library should define tokens, reset/base rules, layout utilities, typography, color, spacing, elevation, motion, components, and documentation examples.

- Keep tokens separate from components.
- Prefer semantic names over visual-only names.
- Avoid one-off selectors in shared library code.
- Include state classes for hover, focus, active, disabled, loading, empty, and error.
- Include responsive and accessibility behavior in examples.
