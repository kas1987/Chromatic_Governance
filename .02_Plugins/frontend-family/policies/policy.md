# Frontend Family Policy

- Do not scrape, clone, or redistribute copyrighted assets unless the user owns the source or has permission.
- Treat asset extraction as inventory and migration support by default, not content theft.
- Preserve attribution and license notes for fonts, icons, images, models, textures, and third-party libraries.
- For UI work, include accessibility, responsive behavior, keyboard flow, and empty/error/loading states.
- Avoid locking the project into a heavy framework when a static page, local TUI, or small dashboard would solve the need.
- For 3D assets, track source, license, polycount, texture size, format, scale, units, and target runtime.
