# Frontend Family

Frontend Family is the UI execution and experience-design plugin family. It helps agents extract webpage assets, build CSS/Tailwind/component libraries, produce quick dashboards, choose local or public UI platforms, design interactive GUIs, and manage Blender/3D asset workflows.

## Core stance

Use this family when the project needs visible user experience work, interface prototyping, visual systems, interactive tools, asset harvesting, front-end implementation guidance, local app shells, or 3D/web asset planning.

## Skills

- `webpage-asset-extract`: inventory and extract assets from a webpage or local HTML bundle.
- `css-library`: design, organize, document, and govern a reusable CSS library.
- `tailwind-system`: build Tailwind tokens, presets, class patterns, and component conventions.
- `component-library`: design a reusable component library with API, variants, and accessibility rules.
- `ui-best-practices`: review UI/UX against usability, accessibility, responsiveness, and interaction heuristics.
- `quick-dashboard`: create fast dashboards, admin panels, KPI views, and monitoring UIs.
- `interactive-gui`: plan and scaffold interactive web GUIs, no-code/low-code UIs, and app-style controls.
- `local-apps`: choose and scaffold local app shells, including TUI, CLI, desktop, local web, and Electron/Tauri-style apps.
- `external-ui-platforms`: select public UI/UX platforms and hosted builders based on use case.
- `blender-3d-assets`: plan advanced Blender, 3D asset, model, texture, and export workflows.

## Policy

Prefer quick prototypes when discovery is unresolved. Prefer design systems and component libraries when the interface will be reused. Prefer accessibility, responsive behavior, and asset rights hygiene by default.
