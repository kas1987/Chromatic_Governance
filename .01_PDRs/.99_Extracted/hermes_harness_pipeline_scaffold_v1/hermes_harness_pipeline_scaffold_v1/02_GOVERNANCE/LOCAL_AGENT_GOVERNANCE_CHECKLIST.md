# Local Agent Governance Checklist

Before execution:

- [ ] Mission packet is present.
- [ ] Objective is clear.
- [ ] Allowed files are listed.
- [ ] Forbidden files are listed.
- [ ] Stop conditions are explicit.
- [ ] Validation commands are listed.
- [ ] Risk and privacy class are listed.
- [ ] Expected output format is listed.

During execution:

- [ ] Stay inside allowed files.
- [ ] Do not modify governance or routing unless mission allows it.
- [ ] Do not invent new tasks.
- [ ] Log assumptions.
- [ ] Stop on ambiguity.

After execution:

- [ ] Run validation commands.
- [ ] Produce eval receipt.
- [ ] Summarize changed files.
- [ ] Note failed checks.
- [ ] Prepare PR summary.
