# PDR Requirements by Mission Level

## M1

No PDR required. Use the basic mission packet only.

## M2 Light PDR

Required sections:
- Problem statement.
- Context.
- Proposed approach.
- Key decisions.
- Risks summary.
- Test plan summary.
- Basic rollback note.

## M3 Standard PDR

Required sections:
- Detailed design.
- Architecture flow.
- Data impact.
- Integration points.
- Test strategy.
- Rollback plan.
- Risk register.
- Resource estimate.
- Decision register.

## M4 Full PDR

Required sections:
- Complete design.
- Alternatives considered.
- Threat/risk model.
- Stakeholder map.
- Data and system impact.
- Full test strategy.
- Full rollback and recovery plan.
- Change governance plan.
- Communication plan.
- Approval/signoff record.

## Principle

A PDR is not decoration. It exists when mission complexity would otherwise force agents to improvise.
